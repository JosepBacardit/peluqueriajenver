# Resolución de revisiones

Lee todos los registros `.ai/reviews/` aplicables y `procedures/review.md` antes de cambiar código. Para cada hallazgo, decide basándote en evidencias: corrígelo con un cambio enfocado mediante TDD o documenta una justificación concisa para no cambiarlo. Actualiza el estado y la resolución del hallazgo y después ejecuta los tests relevantes. No borres en silencio los registros de revisión.
